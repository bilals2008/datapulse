# Changelog

## DataPulse 0.1.3

### ✨ New

- **Open on startup** — a new _Startup_ card in Settings lets DataPulse launch
  automatically when you sign in, so monitoring starts without lifting a finger.

### 🛠 Under the hood

- Releases are now cut on purpose from GitHub Actions instead of firing on every
  push to `main`.

### 📥 Downloads

| Platform              | File                            |
| --------------------- | ------------------------------- |
| Windows               | `.msi` / `.exe`                 |
| macOS (Apple Silicon) | `aarch64.dmg`                   |
| macOS (Intel)         | `x64.dmg`                       |
| Linux                 | `.deb` / `.rpm` / `.AppImage`   |

### 🔄 Updating

Already running DataPulse? You don't need to download anything — open
**Settings → Updates** and hit _Check for updates_ (or just let it check on
startup). It installs and relaunches itself.
